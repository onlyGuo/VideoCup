## 仓库简介

在 GitHub 仓库的 **About → Description** 中填写：

> 本地优先的轻量 Web 视频剪辑工具。多轨时间线、图片叠加、字幕一键 AI 配音、本机加速导出。基于 Vue 3.6 Vapor + Vite + FFmpeg。

英文简介备选：

> A local-first web video editor with multitrack timelines, image overlays, one-click AI voiceovers and native-accelerated export. Built with Vue Vapor, Vite and FFmpeg.
